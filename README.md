# Mein erstes Repo

Willkommen! Dieses Repository wurde als erstes GitHub-Projekt angelegt.

## Über dieses Projekt

Ein kleines Testprojekt zum Kennenlernen von GitHub und Pull Requests.

## Erste Schritte

1. Repository klonen: `git clone https://github.com/Dopi0089/mein-erstes-repo.git`
2. In den Ordner wechseln: `cd mein-erstes-repo`
3. Änderungen vornehmen und einen Pull Request öffnen

Verbesserungsvorschläge sind willkommen!
